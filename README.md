# AttendX Test Scripts

## Project Description
Sample test scripts for the AttendX student attendance application.

## Test Scripts
1. login_test.py - Checks username and password inputs are not empty.
2. attendance_test.py - Checks student ID and attendance status.

## Technologies
- Python
- Git
- GitHub

## How to Run
python login_test.py
python attendance_test.py
